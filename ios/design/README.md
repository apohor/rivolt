# iPhone design tokens

The app looks like the web's new look (`ui_theme_next`). `tokens.json` holds every
value it needs, resolved from the web's own CSS for **dark** and **light**:

- `roles`: semantic colours, each read from one web CSS variable through the same
  cascade the page uses.
- `literals`: colours written straight into a rule or a component: glows, the
  gauge's gradients, card shadows and sheen, the solid bars.
- `scalars`: type sizes, tracking, spacing, radii, motion, gauge geometry, tab bar.
- `icons`: the tab bar's own SVG paths.

Each colour carries its CSS `oklch`, an sRGB `hex` (clamped to sRGB) and `alpha`, plus
the `source` it came from.

**Don't edit `tokens.json` by hand.** It is generated by `web/src/lib/designTokens.ts`.
`web/src/lib/designTokens.test.ts` fails whenever the web changes a value the app
uses. To regenerate it after a deliberate web change, run from `web/`:

```sh
UPDATE_DESIGN_TOKENS=1 npx vitest run src/lib/designTokens.test.ts
```

Then update the app's Theme to match.

Role names, in case you think in other words: "text" = `textPrimary`, "secondary text" =
`textSecondary`, "charging" / "live" = `accent` (fills `accentFill`), "warning" = `estimate`
(amber), "error" / "low battery" = `critical`. Differences from the web are listed under
`platform` in `tokens.json`.

## Building the Swift Theme from it

- **Colours:** `Color(hex:)` with `alpha`, in a `Theme` with dark and light variants, e.g. an
  asset catalog colour set per role, or `Color(uiColor: UIColor { $0.userInterfaceStyle == .dark ? … : … })`.
  The theme follows the system appearance, as the web's System setting does.
- **Glow:** live states only. That means the Now hero while charging (emerald) or
  driving (sky), and the gauge fill while charging. There is no glow on anything at rest.
- **Reduce Motion:** turn off animations and the count-up; show final values.
- **Fonts:** Geist (sans) and Geist Mono, SIL Open Font License 1.1 (`LICENSE-Geist.txt`).
  - The licence declares no Reserved Font Name, so the app may bundle (and subset) them.
  - The licence file must ship with the app: include it in the bundle and in the app's
    acknowledgements.
  - iOS needs the TTF/OTF builds, not the web's woff2. Use the variable `Geist[wght].ttf`
    and `GeistMono[wght].ttf` from the Geist release, with tabular figures (`tnum`).

## Component → tokens

| Web component (source) | Tokens |
|---|---|
| **Page** (`index.css` body) | `roles.background`; tab-shell top bar and tab bar `literals.bar` (solid) |
| **Card** (`components/ui.tsx` `Card`; `index.css` elevation rule) | `roles.card` at 50% alpha on `roles.background`; 1 px `roles.border`; corner `scalars.radius.card` (12); padding 16 (4 × `space.unit`); inner top highlight 1 px `roles.edge`; `literals.cardSheen` (top-down gradient); shadow `literals.cardShadowNear` + `literals.cardShadowFar` |
| **Card title / labels** (`.ui-label`) | `scalars.type.labelSize` (11), weight 500, uppercase, tracking 0.09 em, `roles.textTertiary` |
| **NowCard hero** (`components/NowCard.tsx`, `[data-ui-hero]`) | Card with `roles.card` at 60%, padding 20, `literals.heroTint` light pool; vehicle name = label; headline `type.value` in `roles.textBody`; hero number `type.hero` (36) semibold tabular, `roles.textPrimary` (or `roles.critical` when low, `roles.textTertiary` offline); "%" `type.title` regular, `roles.textSecondary`; border `roles.criticalBorder` at 50% when critical |
| **NowCard while charging / driving** | `literals.glowChargingBorder`, `glowChargingRing`, `glowChargingHalo` (charging, emerald); `glowDrivingBorder`, `glowDrivingHalo` (driving, sky) |
| **Status pill** (`lib/nowState.ts` `statusPill`) | Capsule, 1 px border, 2 × 8 padding, `type.caption` (11). **Live**: text `roles.accent`, border `roles.accentFill` at 30%. **Last seen…** (stale): text `roles.estimate`, border `roles.estimateFill` at 40%. **Asleep / Offline / last seen (fresh)**: text `roles.textSecondary`, border `roles.borderStrong` |
| **ArcGauge** (`components/ArcGauge.tsx`) | 240° arc (`gauge.sweep`) from 150°, radius 52 in 120 × 108, stroke 7, round caps. Track = `roles.textBody` at 0.14. Fill gradient (top-left to bottom-right) `literals.gaugeOkFrom` → `gaugeOkTo`; `gaugeCriticalFrom/To` when low; `gaugeIdleFrom/To` offline. Charge-limit tick 2 px `roles.textPrimary`, from r − 8 to r + 7. Glow `literals.glowGauge` only while charging. Default width 132, height 0.9 × width |
| **Charging-power sparkline** (NowCard) | line `roles.accentFill`, `literals.glowSparkLine` |
| **Charts** (`components/charts.tsx`, `SocTrendChart.tsx`, `IdleAwakeTile.tsx`, `pages/HomePage.tsx`) | fixed sRGB, same in both themes: miles per day `literals.chartMilesBar`; charge level `chartSocCharge` (charging) and `chartSocDrive` (driving), limit line `chartSocLimit` dashed 4/3; idle awake `chartIdleAwakeBar`, tile `chartIdleAwakeTile`. Gridlines `roles.border` at 55%; axis text `type.caption` `roles.textTertiary`; numbers tabular, tracking −0.012 em |
| **Bottom tab bar** (`layout/TabShell.tsx`) | `literals.bar`, top border 1 px `roles.border`; item height `tabBar.minHeight` (56) + home-indicator inset; icon 22 pt from `icons.paths` (24 × 24, stroke 1.8, round caps and joins, no fill); label `type.caption` weight 500; active `roles.accent`, inactive `roles.textTertiary` |
| **Buttons** | solid: `roles.accentButton` with white text, radius `radius.inner` (8) |
| **Estimates** (Money, costs) | `roles.estimate`, written with "about" / "(estimate)" as on the web |

Motion: state changes take `scalars.motion.ms` (200 ms) ease-out; none with Reduce Motion.
