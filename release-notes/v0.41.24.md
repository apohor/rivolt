**Improvements**
- With Rivolt's built-in AI, drive recaps use Claude Haiku 5.5 and efficiency and trip advice use Claude Sonnet 5.5; your own API key keeps the model you chose.
- AI recaps, efficiency and advice get headwind and tailwind right: Rivolt works out the wind against your direction of travel instead of leaving it to the model, and calls very light wind "light".
- Truck pictures missing for some accounts load again the next time the truck connects.
- Importing history from TezLab or ABRP: a file Rivolt can't read now says which columns it expects, and nothing is imported.

**For self-hosters**
- A fresh database is now set up from a single baseline. To upgrade an existing install, first upgrade to v0.41.21 or later, then to this release.
