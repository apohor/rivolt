**Improvements**
- AI drive recaps now use Claude Haiku 5.5, and efficiency and trip advice use Claude Sonnet 5.5. Settings shows which model each one uses.
- AI advice gets headwind and tailwind right: Rivolt works out the wind against your direction of travel instead of leaving it to the model, and calls calm air "light".
- Truck pictures that were missing for some accounts now load.

**For self-hosters**
- A fresh database is now set up from a single baseline. To upgrade an existing install, first upgrade to v0.41.21 or later, then to this release.
